# 慢熟 × 選邊站｜對話卡網頁版

把《對話卡題庫》Excel 做成可以直接在手機、平板、電腦上抽卡的網頁。

- **慢熟｜深聊卡**（150 張）：Lv.1 暖身 → Lv.2 認識 → Lv.3 深聊
- **選邊站｜二選一卡**（150 張）：Lv.1 輕鬆 → Lv.2 價值觀 → Lv.3 兩難，其中 14 張卡背藏有心理學偏誤解說
- **🔥 全民吵架｜生活爭議**（104 張，6 個主題）：南北粽、蒸炸肉圓、衛生紙方向、炸物擠檸檬、句號像在生氣……只收兩邊都理直氣壯的現實爭議；每題有陣營名，投完看比例，可發起翻盤挑戰，一輪結束出總結

### 兩套二選一怎麼分

| | 選邊站 | 全民吵架 |
|---|---|---|
| 問法 | 「你寧願」：假設情境、被迫取捨 | 「你是哪一派」：現實中早就有答案的習慣與口味 |
| 聊的是 | 你是怎樣的人 | 你屬於哪一國 |
| 判斷方法 | 要加上「如果」「一輩子只能」才成立 | 大家現在就有答案，還會覺得另一派很怪 |

兩套都不收時事、人名與品牌題。

## 功能

1. **設定頁**：先選當次使用情境，自動帶出合適的卡片
   | 情境 | 卡角標示 | 等級 |
   |---|---|---|
   | 初次見面／同事聚會 | 全場合 | Lv.1–2 |
   | 朋友聚會 | 全場合、朋友以上 | Lv.1–3 |
   | 老朋友深聊 | 全場合、朋友以上 | Lv.2–3 |
   | 情侶約會 | 全部（含情侶限定） | Lv.1–3 |
   | 自訂 | 自選 | 自選 |
2. 套組可選「混合玩／慢熟／選邊站」；混合時同一等級先用選邊站暖場再換慢熟
3. 進階調整：主題、等級、卡角標示、由淺入深或完全隨機、題數
4. 由淺入深模式在升級前會停下來問「要進到下一級嗎？」，也可以就此結束
5. 選邊站：A／B 計票、倒數三秒、隱藏偏誤卡可翻到卡背看解說與原始研究出處
6. 框架效應實驗：讓 P2-21「存活率 90%」與 P2-22「死亡率 10%」前後連抽
7. **深淺色切換**（淺色／跟隨系統／深色），會記住上次的選擇
8. 參考來源頁：列出每個偏誤的原始研究（附 DOI 連結）

鍵盤操作：`←` `→` 換卡、空白鍵翻卡背、`1` `2` 投票。

## 和夥伴一起玩

**擺設**
- 用一台手機或平板放桌子中間，或用電腦投到電視或投影幕，大家看同一個畫面。
- 在設定頁選好情境（例如「朋友聚會」），再按「開始抽卡」。

**玩慢熟（深聊卡）**
1. 大家輪流當「抽卡的人」，負責唸題目、按「下一張」。
2. 可以只讓抽卡的人回答，也可以每個人都答同一題。
3. 每張卡都能按「跳過」，不用解釋。
4. 用「由淺入深」玩的話，升級前畫面會問「要進到下一級嗎？」，大家一起決定。

**玩選邊站（二選一卡）**
1. 抽卡的人唸出題目和 A、B 兩個選項。
2. 按「倒數 3 秒」，倒數結束時所有人同時比 1 或 2。
3. 抽卡的人照手勢點 A、B 按鈕記票（也可以按鍵盤的 1、2），票數會顯示在選項上。
4. 選少數的那一邊先說理由，可以試著說服別人換邊。
5. 卡片右下角有「🧠 翻到卡背」的話，等大家吵完再翻開看心理學解說。

**🔥 全民吵架專區**
1. 玩法跟選邊站一樣：唸題、倒數、同時比 1 或 2，再記票。
2. 記完票，選項上會出現比例條；越接近一半一半越值得吵。
3. 翻盤挑戰：少數派推一位代表，按「🔄 翻盤挑戰」說服 30 秒，大家再投一次，看會不會有人倒戈。
4. 一輪結束會出現「我們這群人的選擇」總結，以陣營名顯示，並標出本輪最大爭議與翻盤題，可以截圖分享。

## 使用方式

純靜態網頁，無需安裝。直接開 `index.html`，或使用 GitHub Pages 網址。

## 更新題庫

修改 `data/cards.xlsx` 後重新產生資料檔：

```bash
pip install openpyxl
python tools/build_data.py data/cards.xlsx
```

會覆寫 `js/cards.js`，並自動執行**重複題檢查**：

- 用概念關鍵字（`CONCEPTS`）找出「同一個主題、換句話說」的題目，再加上字面相似度檢查。
- 只比對「全民吵架 vs 選邊站」與「全民吵架內部」。
- 人工確認過不算撞題的組合，記在 `REVIEWED_OK` 並寫明理由；新增題目碰到新主題時，請把關鍵字補進 `CONCEPTS`。

## 檔案結構

```

js/app.js           設定、洗牌、抽卡邏輯
js/cards.js         題庫資料（由 Excel 產生）
js/sources.js       參考來源
data/cards.xlsx     原始題庫
tools/build_data.py Excel → js/cards.js
```
